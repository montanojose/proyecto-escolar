# Electrodesafío

Plataforma educativa de la escuela Gral. Enrique Mosconi con actividades de electrotecnia, matemática y lengua, gestión de clases y seguimiento de puntos.

## Tecnologías

PHP, MySQL, React, TypeScript y Vite.

## Instalación

1. Instalar las dependencias con `npm ci`.
2. Crear la base de datos con `database/estructura.sql` y seguir la documentación de `docs/` y `database/migrations/`.
3. Configurar las variables `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER` y `DB_PASS` para el servidor PHP.
4. Compilar el frontend con `npm run build` y configurar el servidor web para servir `public_html/`.

## Datos de ejemplo

Los registros de alumnos incluidos son ficticios. Los respaldos de producción y los datos personales de estudiantes se excluyen de esta distribución. No importar datos de demostración sobre una base de producción.
