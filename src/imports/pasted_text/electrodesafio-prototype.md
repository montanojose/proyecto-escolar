Diseña y genera un prototipo web funcional, moderno y completamente responsive para una plataforma educativa de Electrotecnia destinada a estudiantes de escuela secundaria técnica.

NOMBRE PROVISORIO:
ElectroDesafío

OBJETIVO DEL PROYECTO:
La plataforma permitirá que los alumnos seleccionen una actividad, ingresen con su DNI, resuelvan ejercicios interactivos de Electrotecnia y obtengan puntos que luego podrán utilizar para mejorar la nota de un examen.

La experiencia debe ser sencilla, didáctica, entretenida y visualmente atractiva. No debe parecer una plataforma empresarial, universitaria ni una página genérica generada con inteligencia artificial.

FLUJO PRINCIPAL DEL ALUMNO:

1. Pantalla de inicio.
2. Selección de una actividad disponible.
3. Identificación del alumno mediante DNI.
4. Presentación de la consigna y las reglas.
5. Resolución de aproximadamente 10 ejercicios.
6. Validación inmediata de cada respuesta.
7. Pantalla final con resultado, puntos obtenidos y resumen de la actividad.

PANTALLA DE INICIO:

Crear una portada atractiva con:

- Nombre y logotipo provisorio de ElectroDesafío.
- Mensaje principal: “Aprendé, resolvé y ganá puntos”.
- Breve explicación del funcionamiento.
- Botón principal: “Elegir actividad”.
- Ilustraciones relacionadas con circuitos eléctricos, resistencias, lámparas, instrumentos de medición y energía.
- Un pequeño indicador con tres pasos:
  “Elegí una actividad → Ingresá tu DNI → Resolvé el desafío”.
- Animaciones suaves al cargar la pantalla.
- Fondo con formas inspiradas en diagramas eléctricos, líneas conductoras y nodos, sin recargar el diseño.

SELECCIÓN DE ACTIVIDADES:

Mostrar las actividades mediante tarjetas visuales.

Cada tarjeta debe contener:

- Nombre de la actividad.
- Imagen o ilustración representativa.
- Descripción breve.
- Cantidad de ejercicios.
- Nivel de dificultad.
- Puntos disponibles.
- Estado: disponible, próxima o finalizada.
- Botón “Comenzar actividad”.

El alumno debe seleccionar una actividad antes de ingresar su DNI.

Las actividades disponibles deben destacarse claramente. Las actividades bloqueadas o finalizadas deben verse diferentes, pero seguir siendo legibles.

VALIDACIÓN POR DNI:

Después de elegir la actividad, mostrar una pantalla simple con:

- Nombre de la actividad seleccionada.
- Campo para ingresar DNI.
- Botón grande “Continuar”.
- Mensajes claros de error o validación.
- Estado de carga mientras se comprueba el DNI.
- Mensaje si el DNI no se encuentra en la lista.
- Mensaje si el alumno ya completó la actividad.
- Confirmación con el nombre y apellido del alumno cuando el DNI sea válido.

No utilizar correo electrónico, nombre de usuario ni contraseña.

PANTALLA DE INSTRUCCIONES:

Antes de comenzar, mostrar:

- Nombre de la actividad.
- Objetivo.
- Cantidad de ejercicios.
- Puntos en juego.
- Tiempo estimado.
- Reglas de participación.
- Advertencia de que, una vez iniciada, quedarán registrados los intentos.
- Botón “Comenzar desafío”.

PANTALLA DE EJERCICIOS:

Diseñar una interfaz enfocada y fácil de usar que incluya:

- Número del ejercicio actual, por ejemplo “Ejercicio 3 de 10”.
- Barra de progreso visual.
- Puntaje acumulado.
- Enunciado claramente legible.
- Área amplia para mostrar una imagen o diagrama de un circuito eléctrico realizado por el profesor.
- Distintos tipos de respuestas:
  - Selección múltiple.
  - Verdadero o falso.
  - Ingreso de un valor numérico.
  - Selección de componentes.
  - Ordenamiento de pasos.
- Botón principal “Validar respuesta”.
- Botones “Anterior” y “Siguiente” cuando corresponda.
- Mensajes de respuesta correcta e incorrecta.
- Explicación breve después de validar.
- Posibilidad de volver a intentar cuando la configuración de la actividad lo permita.

Cuando una respuesta sea correcta, mostrar una animación breve y satisfactoria, por ejemplo una pequeña chispa, una corriente recorriendo un circuito o un componente encendiéndose.

Cuando sea incorrecta, mostrar una devolución amable y pedagógica. No utilizar mensajes agresivos ni hacer sentir mal al alumno.

No mostrar todas las preguntas en una única página. Presentar un ejercicio por pantalla para mantener la concentración.

SISTEMA DE PUNTOS:

La plataforma debe comunicar claramente que los puntos obtenidos podrán utilizarse posteriormente en un examen.

Preparar la interfaz para reglas como:

- Los primeros cinco alumnos que completen correctamente la actividad obtienen 10 puntos.
- Los siguientes alumnos obtienen 5 puntos.
- El sistema debe mostrar los puntos disponibles antes de comenzar.
- No mostrar información privada de otros estudiantes.
- Puede mostrarse un indicador general como “Todavía quedan premios de 10 puntos”, sin mostrar nombres.

PANTALLA DE RESULTADOS:

Al finalizar, mostrar:

- Nombre del alumno.
- Actividad completada.
- Cantidad de respuestas correctas.
- Cantidad de intentos.
- Porcentaje obtenido.
- Puntos ganados.
- Mensaje destacado: “¡Ganaste 10 puntos para usar en tu examen!”.
- Resumen visual de respuestas correctas e incorrectas.
- Botón “Volver a las actividades”.
- Animación de celebración breve, juvenil y moderada.

PANEL DEL PROFESOR:

Crear también un panel administrativo separado que permita visualizar:

- Actividades creadas.
- Actividades disponibles, programadas y finalizadas.
- Cantidad de alumnos participantes.
- Alumnos que completaron cada actividad.
- Respuestas correctas e incorrectas.
- Número de intentos.
- Puntos otorgados.
- Orden en que finalizaron los alumnos.
- Botones para crear, editar, activar, desactivar y duplicar actividades.
- Posibilidad de cargar la imagen del circuito de cada ejercicio.
- Configuración de respuestas correctas y devoluciones.
- Buscador de alumnos por nombre o DNI.
- Tabla responsive que se transforme en tarjetas en pantallas pequeñas.

ESTILO VISUAL:

Crear una identidad original inspirada en la electricidad, los circuitos y los desafíos.

Usar esta paleta como punto de partida:

- Fondo crema claro: #FFF8EA
- Grafito oscuro: #17212B
- Verde eléctrico: #C7F464
- Coral energético: #FF6B5E
- Turquesa: #28C2D1
- Blanco: #FFFFFF

El verde eléctrico y el coral deben utilizarse principalmente como acentos. Mantener buen contraste y legibilidad.

Evitar los estilos genéricos frecuentes en páginas creadas con IA:

- No usar degradados morados y azules.
- No abusar del efecto glassmorphism.
- No llenar la pantalla con brillos.
- No utilizar tarjetas idénticas para absolutamente todo.
- No hacer que parezca una plataforma bancaria o corporativa.

Utilizar:

- Tipografía moderna, juvenil y muy legible.
- Títulos con personalidad.
- Botones grandes, claros y agradables.
- Bordes redondeados moderados.
- Sombras suaves.
- Iconos relacionados con electricidad.
- Pequeños detalles gráficos inspirados en pistas de circuitos impresos.
- Jerarquía visual clara.
- Espacios equilibrados.
- Estados hover, focus, active, disabled, correct e incorrect.

ANIMACIONES E INTERACCIONES:

Incluir animaciones suaves y con propósito:

- Aparición progresiva de las tarjetas.
- Movimiento sutil en botones al pasar el cursor.
- Barra de progreso animada.
- Transiciones entre ejercicios.
- Animación de circuito encendido al acertar.
- Feedback visual al presionar botones.
- Celebración moderada al finalizar.

Respetar “prefers-reduced-motion” para usuarios que tengan desactivadas las animaciones.

RESPONSIVE DESIGN:

La plataforma debe adaptarse correctamente a:

- Teléfonos pequeños desde 320 px.
- Teléfonos grandes.
- Tablets.
- Notebooks.
- Monitores de escritorio.

Diseñar versiones específicas para móvil, tablet y escritorio.

En teléfonos:

- Utilizar una sola columna.
- Mantener botones fáciles de tocar.
- Evitar desplazamientos horizontales.
- Ajustar los diagramas eléctricos sin recortarlos.
- Mantener visible el progreso.
- Convertir tablas administrativas en tarjetas.
- Utilizar menú hamburguesa cuando sea necesario.

ACCESIBILIDAD:

- Contraste adecuado entre texto y fondo.
- Tamaño de texto mínimo legible.
- Áreas táctiles de al menos 44 × 44 px.
- Etiquetas visibles en formularios.
- Navegación mediante teclado.
- Estados de foco claramente visibles.
- No comunicar respuestas correctas o incorrectas únicamente mediante colores.
- Agregar iconos y texto en los mensajes de validación.

ESTRUCTURA DEL CÓDIGO:

Generar el proyecto con HTML semántico, CSS y JavaScript. Puede utilizar archivos PHP para las vistas porque posteriormente se conectará con una base de datos MySQL en un servidor propio.

No colocar CSS dentro del HTML ni utilizar estilos inline.

Separar el código, como mínimo, en:

- assets/css/variables.css
- assets/css/global.css
- assets/css/components.css
- assets/css/pages.css
- assets/css/responsive.css
- assets/js/app.js
- assets/js/activities.js
- assets/images/
- includes/header.php
- includes/footer.php
- index.php
- actividades.php
- acceso.php
- instrucciones.php
- ejercicio.php
- resultado.php
- admin/index.php

Conectar todos los archivos CSS y JavaScript utilizando versionado automático para evitar que el navegador muestre versiones guardadas en caché.

En los archivos PHP utilizar una estrategia como:

<link rel="stylesheet" href="assets/css/global.css?v=<?php echo filemtime('assets/css/global.css'); ?>">

Aplicar el mismo sistema a todos los archivos CSS y JavaScript, adaptando correctamente las rutas según la carpeta en la que se encuentre cada página.

REQUISITOS TÉCNICOS:

- No utilizar frameworks pesados.
- Mantener el código organizado y fácil de editar.
- Utilizar variables CSS para colores, tamaños, sombras y espaciados.
- Evitar valores repetidos innecesariamente.
- Utilizar Flexbox y CSS Grid.
- Preparar componentes reutilizables.
- Incorporar datos de demostración realistas.
- No implementar todavía una conexión real con la base de datos.
- Simular la validación del DNI, las actividades y los resultados para probar todo el recorrido.
- Dejar la estructura preparada para conectar posteriormente PHP con MySQL.
- No utilizar textos genéricos como “Lorem ipsum”.

RESULTADO ESPERADO:

Crear una experiencia completa y navegable que permita probar el recorrido del alumno desde la selección de la actividad hasta la obtención de puntos.

Priorizar la claridad y la facilidad de uso. La plataforma debe resultar atractiva para adolescentes sin parecer infantil. Debe transmitir la idea de desafío, progreso y aprendizaje práctico de Electrotecnia.
